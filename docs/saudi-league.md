# الدوري السعودي ⚽

مربع في الرئيسية تحت «المتاجر» و«البطولات والفعاليات»، وصفحة كاملة فيها:

| الجزء | وش فيه |
|---|---|
| **القادمة** | المباريات المباشرة فوق (النتيجة والدقيقة ونقطة حمرا تنبض)، وبعدها القادمة مجمّعة باليوم بتوقيت الرياض، مع جرس «ذكّرني» لكل مباراة |
| **النتائج** | آخر النتائج (الأحدث أول)، والمؤجلة والملغاة معها |
| **الترتيب** | جدول الدوري: المركز، لعب، فرق الأهداف، النقاط، وشكل آخر ٥ مباريات (ف/ت/خ). فريقك مظلّل |
| **صفحة المباراة** | لوحة النتيجة، عدّاد تنازلي للبداية، الموعد والملعب والجولة، **«احجز تذكرتك»** (يفتح المنصة الرسمية)، «ذكّرني»، مشاركة، شكل الفريقين وترتيبهم، ومواجهاتهم هالموسم |
| **فريقي** | تختار فريق واحد ← تذكير تلقائي قبل كل مباراة له، والنتيجة أول ما تخلص. ومربع الرئيسية يعرض مباراته الجاية |

- **التذكير:** قبل المباراة بـ ٦٠ دقيقة (المالك يغيّرها: ٣٠ / ٦٠ / ١٢٠) يوصل إشعار «⚽ الهلال × النصر — تبدأ الساعة 9:00 م في …». ولما تخلص: «انتهت المباراة ⚽ — الهلال 3 - 2 النصر». الإشعار يفتح صفحة المباراة.
- **التذاكر:** ما نبيع تذاكر ولا ناخذ عمولة. الزر يفتح المنصة الرسمية لتذاكر الدوري (الافتراضي `https://webook.com/ar/spl`، والمالك يغيّره). يظهر بس قبل بداية المباراة.
- **الشعارات:** ما نعرض شعارات الأندية (علامات تجارية). كل فريق له دائرة بحرف اسمه وألوان لبسه المعروفة.
- **التحديث في التطبيق:** الصفحة تحدّث نفسها كل دقيقة وقت المباريات بس (وقت ما فيه مباراة ما تطلب شي).

## ١) كيف يمشي

```
pg_cron كل دقيقة ← run_league()
  ├─ موقّف؟ ← لا شي
  ├─ _league_ft_notices(): مباريات خلصت (ft_pending) ← إشعار النتيجة لمشجعي الفريقين ولمن طلب «ذكّرني»
  ├─ _league_remind(): المباريات اللي تبدأ خلال remind_minutes ← إشعار لمن طلب «ذكّرني»، ولمشجعي الفريقين مرة لكل موعد
  ├─ طلب سابق للحين ما رجع (أقل من ٣ دقايق)؟ ← ننتظر (waiting، ما تتداخل التشغيلات)
  ├─ آخر طلب طاح قبل أقل من ١٠ دقايق؟ ← ننتظر (backoff، عشان ما نحرق الطلبات اليومية)
  ├─ وقت مباراة (مباشرة وبدأت قبل أقل من ٤ ساعات، أو تبدأ خلال ٣ دقايق، أو موعدها فات بأقل من ساعتين ونص)؟ ← live كل live_every_min دقايق (٥)
  └─ وإلا ← full كل full_every_hours ساعات (٣)، وبعد نهاية أي مباراة بـ ٧٠ دقيقة تقريباً (المزوّد يحدّث الترتيب كل ساعة)
       └─ pg_net ← دالة league-sync (مع x-league-key من الـ vault)
            ├─ live: كل مباراة بدأت قبل أقل من ٦ ساعات أو تبدأ خلال ١٠ دقايق وما انتهت ← GET /match?slug=<الزوج>
            │        (الرابط حق الزوج ويرجع آخر مواجهة بدأت، فنقبله بس لو معرّفه نفس المحفوظ في source_ref)
            └─ full: GET /standings ثم GET /team?limit=30 لكل نادي (١٩ طلب بالتتابع، بينها ٣٥٠ مللي ثانية)،
                     وبعدها /match لمباريات فات موعدها بساعتين وما وصلت نهايتها (لين ١٢)
            └─ league_ingest(): تحفظ الفرق والمباريات والترتيب ومرجع المباراة. مباراة خلصت الحين ← ft_pending
                 وأي خطأ (حتى بالحفظ نفسه) ينكتب بـ last_error ← backoff
```

- **الموسم:** سنة البداية (2026 = موسم 2026–2027). من يوليو يصير موسم السنة نفسها، وقبله اللي قبلها. المالك يقدر يثبّت موسم بإضافة `season` للإعداد.
- **المصدر:** [SportScore](https://sportscore.com/developers/) مجاني بدون مفتاح. ما عنده معرّفات رقمية، فالدالة تصنع رقم ثابت للفريق من اسمه وللمباراة من معرّفها في الرابط. ما يعطي الجولة ولا الملعب ولا شكل آخر ٥ مباريات (التطبيق يحسب الشكل من النتائج).
- **التغطية:** جدول كل نادي يرجع آخر ٣٠ مباراة فيه، فالأندية اللي باقي لها أقل من ٣٠ تجيب معها نتائجها الأخيرة، والمجموع يغطي الموسم تقريباً. كم مباراة قديمة بين ناديين مشاركين بآسيا ممكن ما تطلع بالنتائج، والترتيب دايم كامل.
- **الأسماء بالعربي:** المزوّد يرجع الأسماء بالإنجليزي، و`_league_team_ar` يحوّل الأندية المعروفة (الهلال، النصر، الاتحاد، الأهلي، القادسية…). نادي جديد ما يعرفه يطلع باسمه الإنجليزي لين المالك يكتب اسمه:
  ```sql
  update league_teams set name_ar = 'اسم النادي' where id = <المعرّف>;
  ```
  (ما ينكتب فوقه بالتحديث الجاي).
- **الطلبات اليومية تقريباً:** full كل ٣ ساعات = ١٥٢ طلب، ووقت المباريات طلب لكل مباراة كل ٥ دقايق (جولة فيها ٩ مباريات ≈ ٣٠٠). الحد المجاني تقريباً ١٠ آلاف طلب يومياً لكل IP.
- **الخطأ:** أي خطأ من المزوّد (ضغط 429/503 بعد إعادة وحدة، الشبكة، رد غريب) أو بالحفظ ينكتب في `league_sync.last_error` ويطلع للمشرف في لوحة إدارة التطبيق ← الدوري السعودي، والقاعدة تنتظر ١٠ دقايق قبل تعيد.
- **إشعار النتيجة:** بس لمباراة بدأت قبل أقل من ٦ ساعات. لو الدوري كان موقّف أو المزوّد معطّل أيام، النتائج القديمة تنحفظ بدون ما تطلع إشعارات.
- **مباراة معلّقة أو بيانات عالقة:** حالة «مباشر» لمباراة بدأت قبل أكثر من ٤ ساعات ما تشغّل التحديث المباشر، وتطلع في النتائج بـ «معلّقة» أو «لم تكتمل».
- **التأجيل:** لو تغيّر موعد مباراة بعد ما انرسل تذكيرها، التذكير ينرسل من جديد على الموعد الجديد.
- **«فريقي»:** لو شلت فريقك يوقف كل شي يخصه (التذكير التلقائي ما ينكتب كأنك طلبته).

## ٢) قرارات المالك قبل التشغيل

1. **الإسناد (شرط المصدر المجاني):** «Powered by SportScore» برابط لموقعهم يظهر تحت صفحة الدوري وصفحة المباراة و«فريقي» ومربع الرئيسية. لا تشيله. شروطهم مكتوبة للمواقع، فلو تبي تأكيد إن الشكل هذا يكفي في تطبيق جوال: api@sportscore.com. الاستخدام التجاري بدون الإسناد يحتاج خطتهم المدفوعة. الشروط: https://sportscore.com/developers/terms/
2. **التشغيل:** لوحة إدارة التطبيق ← الدوري السعودي ← «تشغيل الدوري في التطبيق». أول تحديث يصير خلال دقيقة، وبعدها يطلع المربع في الرئيسية (عند مستخدمي النسخة اللي فيها الميزة).
3. **الخصوصية:** ما ينرسل للمزوّد أي شي عن المستخدمين: الطلب فيه اسم الدوري أو النادي أو المباراة بس. «فريقي» و«ذكّرني» محفوظة عندنا، وصاحبها بس يشوفها، وتنحذف مع الحساب.

## ٣) النشر (مرة وحدة)

```bash
# ١) الترحيل
supabase db push          # أو الصق 20261015000960_saudi_league.sql ثم 20261019000970_league_sportscore.sql في SQL Editor

# ٢) الدالة (بدون تحقق التوكن: القاعدة تناديها بمفتاح league_key وهي تتأكد منه)
supabase functions deploy league-sync --no-verify-jwt
```

```sql
-- ٣) رابط الدالة في الـ vault (مرة وحدة)
select vault.create_secret('https://<ref>.supabase.co/functions/v1/league-sync', 'league_url');
```

والمفتاح `league_key` ينصنع لحاله مع الترحيل، و`arq-league` يتجدول كل دقيقة.

## ٤) الإيقاف والرجوع

- **إيقاف:** لوحة إدارة التطبيق ← الدوري السعودي ← اطفِ «تشغيل الدوري». المربع والصفحة يختفون، والتذكير يوقف، وما ينطلب شي من المزوّد.
- **إيقاف الجدولة كلها:** `select cron.unschedule('arq-league');`
- **فحص سريع:**
  ```sql
  select public.run_league();          -- off / idle / waiting / backoff / live / full (+ :not_configured لو الرابط ناقص)
  select * from league_sync;           -- آخر تحديث، آخر خطأ، الطلبات الباقية
  ```
