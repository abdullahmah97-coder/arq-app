# أرك — ARQ

**تحرّك بهدف. — Move with Intention.**

تطبيق جوال رياضي اجتماعي (iOS و Android) لكل الأندية، بالعربي والإنجليزي:

- **تسجيل حساب** مع اختيار الجنس (ذكر / أنثى) واسم مستخدم.
- **إعداد أولي**: الوزن والطول وسنة الميلاد والهدف والمستوى وأيام التمرين + **صورة للجسم** (اختيارية وخاصة).
- **خطة أسبوعية** (تمارين + وجبات بأكلات سعودية) مولّدة بالذكاء الاصطناعي (Claude) مع تحليل الصورة، ومع مولّد احتياطي بالقواعد يشتغل بدون إنترنت.
- **تسجيل الحضور بالموقع (Check-in)**: يتأكد الخادم إنك داخل نطاق النادي، ويسجل وقت الدخول والخروج ومدة الجلسة.
- **نقاط وسلسلة أيام** ولوحة صدارة أسبوعية (الأصدقاء / ناديي / الكل).
- **أصدقاء وتحديات**: تحدَّ أصدقاءك على أكثر أيام حضور أو تمارين أو نقاط، والفائز يأخذ 50 نقطة.
- **مجتمع**: منشورات بالصور، إعجابات، تعليقات، وإرفاق حضورك في النادي بالمنشور.
- **متابعة التقدم**: سجل الوزن مع صور تقدّم خاصة ورسم للاتجاه.

## النبض: ربط الجوال والساعة ⌚ (مثل WHOOP و Google Fit)

- **المصادر:** Apple Health على الآيفون (Apple Watch، وأي تطبيق يكتب في Health مثل WHOOP / Oura / Garmin)، و **Health Connect** على أندرويد (Pixel Watch، Galaxy Watch، Fitbit، WHOOP، Garmin…).
- **البيانات:** الخطوات، السعرات النشطة، المسافة، النوم بمراحله (عميق/REM/خفيف/استيقاظ)، نبض الراحة، HRV، ودقائق مناطق النبض.
- **الجاهزية 0–100٪:** HRV ونبض الراحة مقابل معدّلك الشخصي لآخر 30 يوماً + أداء النوم مقابل احتياجك. أخضر ≥67، أصفر 34–66، أحمر <34.
- **الإجهاد 0–21:** من دقائق مناطق النبض (TRIMP) على مقياس لوغاريتمي، أو من السعرات النشطة/الخطوات إن لم تتوفر.
- **احتياج النوم:** 7.5 ساعة + إضافة حسب إجهاد اليوم + جزء من دين النوم.
- **تمرين اليوم يتكيّف تلقائياً:** أحمر = مجموعات أقل وشدة خفيفة وكارديو منطقة 2، أصفر = مجموعة أقل في التمارين المساعدة.
- **اجتماعي:** 10,000 خطوة = +5 نقاط (مرة يومياً)، ترتيب خطوات الأصدقاء، وتحديات على **أكثر خطوات**.
- المحرك في `src/lib/health/score.ts` (حتمي ومختبر)، والمزوّدات في `provider.ios.ts` / `provider.android.ts`، والمزامنة مع الخادم عبر `sync_daily_health`.
- **يتطلب بناء تطوير** (لا يعمل في Expo Go): `npx expo run:ios` / `npx expo run:android` أو EAS. على الويب يظهر وضع البيانات التجريبية.
- iOS: فعّل HealthKit capability (الإضافة `@kingstinct/react-native-healthkit` تضبطها تلقائياً). Android: الحد الأدنى SDK 26، وصلاحيات القراءة مضافة في `app.json`.

## شرح التمارين ثلاثي الأبعاد 🧍

- 44 تمريناً بحركة كاملة على **شخصية ARQ واقعية (رجل أو امرأة)** بملابس مجموعة ARQ: الرجل بتيشيرت بدون أكمام أخضر داكن وشورت بلوحة جانبية ولفافات معصم، والمرأة بجاكيت كريمي بسحّاب وليقنز بخط برتقالي جانبي وحجاب رياضي — مع شعار ARQ على الصدر.
- العضلات العاملة تُضاء على الجسم والملابس (أساسية بالبرتقالي، مساعدة بالكهرماني)، واضغط على أي عضلة لشرحها: الاسم التشريحي، مكانها، وظيفتها، وكيف تحس فيها.
- الخطوات، الأخطاء الشائعة، والتنفس لكل تمرين. التدوير بالسحب، وإيقاف/تبطيء الحركة.
- الشخصيات مبنية من **MakeHuman / MPFB2 (رخصة CC0)** عبر `tools/build_athlete.py`:
  ```bash
  python3 tools/build_athlete.py <mpfb2/src/mpfb/data> male   assets/models/athlete_male.glb
  python3 tools/build_athlete.py <mpfb2/src/mpfb/data> female assets/models/athlete_female.glb
  ```
- المحرك: `src/three/` (الهيكل السائق، الحركات، النقل للنموذج الواقعي، الدليل، التشريح)، والعارض: `src/components/exercise/ExerciseViewer.tsx` (React Three Fiber + expo-gl).

## سجل التمارين والمقارنة 📈

- ابدأ التمرين من **خطتي** أو من **المدرب الذكي** وسجّل كل مجموعة (الوزن × العدّات) بضغطة ✓، مع مؤقت راحة.
- تحت كل تمرين: **آخر مرة** سويته (مثلاً `60×10 · 60×9`) و**اقتراح اليوم** (زيادة تدريجية: كمّلت الحد الأعلى → +2.5 كجم، والأرجل +5).
- بعد الإنهاء: **جدول مقارنة مع آخر جلسة مماثلة** (نفس العضلات — ترابيس مع ترابيس): أفضل مجموعة، الحجم الكلي وتغيّره ٪، المدة، و🏆 للأرقام الشخصية (أعلى 1RM تقديري).
- صفحة كل تمرين 3D فيها **سجلك** وتطوّر أفضل مجموعة، و**سجل التمارين** في صفحة حسابي.
- المحرك في `src/lib/training/stats.ts` (مختبر)، والجداول `workout_sessions` و `workout_sets` خاصة بصاحبها.

## مدرب ARQ الذكي ✨ (الزر الماسي في منتصف الشريط)

- اكتب أو اختر طلبك: «تمرين صدر ٣٠ دقيقة»، «تمرين بالبيت بدون أدوات»، «وش أتمرن اليوم حسب جاهزيتي؟»، «كيف أسوي سكوات صح؟»، «وجبة بعد التمرين»، «افتح تقرير InBody».
- يرد بتمرين جاهز من مكتبة الـ 44 تمرين (كل تمرين يفتح بالمجسّم 3D)، مع زر **ابدأ** و **أضفه لخطة اليوم**، أو يفتح لك الصفحة المطلوبة.
- يعرف ملفك (الهدف، المستوى)، وجاهزيتك ونومك من الساعة، وخطة اليوم — فيخفف التمرين تلقائياً لو جاهزيتك منخفضة.
- الذكاء الاصطناعي عبر `supabase/functions/coach` (حد 40 رسالة يومياً لكل مستخدم، بدون حفظ نص المحادثات في الخادم). بدون مفتاح أو بدون إنترنت يرد **المدرب المحلي** (`src/lib/coach/local.ts`) للطلبات الشائعة.
- النشر: `npx supabase functions deploy coach`

## تقرير InBody 📊

- **الإضافة:** من «حسابي ← تقارير InBody» أو بطاقة «حسّن خطتك» في صفحة الخطة. صوّر التقرير أو اختره من الصور أو ارفعه PDF أو أدخل الأرقام يدوياً.
- **القراءة:** الدالة `supabase/functions/analyze-inbody` تقرأ أي جهاز InBody (270/570/770/970…) بالذكاء الاصطناعي وتستخرج كل الأرقام، ثم يراجعها المستخدم ويصحّحها قبل الحفظ.
- **التحليل** (`src/lib/inbody/analyze.ts`) حتمي وقابل للاختبار:
  - نوع الجسم والهدف المقترح (خسارة دهون، بناء، إعادة تشكيل، حفاظ) مع معدل تغيير أسبوعي آمن والمدة المتوقعة.
  - السعرات من **BMR المقاس** بدل المعادلة، ولا تنزل تحته.
  - البروتين من **الكتلة الخالية من الدهون**.
  - الأجزاء الضعيفة (<90%) تحصل على تمارين إضافية، وعدم التوازن بين اليمين واليسار (>5%) يحصل على تمارين بطرف واحد تبدأ بالأضعف.
  - الدهون الحشوية العالية (مستوى ≥10 أو مساحة ≥100 سم²) تضيف كارديو.
  - **ECW ≥ 0.39** (احتمال وذمة) يظهر كتنبيه أول ويخلي الشدة معتدلة مع نصيحة بمراجعة طبيب.
- **الخصوصية:** التقارير في جدول وحاوية خاصة لا يراها إلا صاحبها.
- **الاختبار:** `npm run test:inbody` على التقريرين المرفقين في `tests/fixtures` (InBody770 و InBody970S).
- **النشر:** `npx supabase functions deploy analyze-inbody` + تشغيل `supabase/migrations/20260926010000_inbody.sql`.

## التشغيل خطوة بخطوة

### 1) إنشاء مشروع Supabase
1. أنشئ مشروعاً على [supabase.com](https://supabase.com).
2. من **SQL Editor** شغّل كل ملفات `supabase/migrations/` **بالترتيب** (الأساس، InBody، الصحة، ملاحظات المختبرين، حذف الحساب، المدرب الذكي)، ثم `supabase/seed.sql` (أندية تجريبية).
   - أو بالـ CLI: `npx supabase link` ثم `npx supabase db push`.
3. من **Authentication > Providers** تأكد إن Email مفعّل. (للتجربة السريعة تقدر تطفي Confirm email.)

### 2) تفعيل الذكاء الاصطناعي (اختياري لكن مستحسن)
```bash
npx supabase secrets set ANTHROPIC_API_KEY=sk-ant-...
npx supabase secrets set ANTHROPIC_MODEL=claude-sonnet-5   # اختياري
npx supabase functions deploy generate-plan
npx supabase functions deploy analyze-inbody
npx supabase functions deploy coach
```
بدون هذي الخطوة التطبيق يشتغل عادي ويولّد خطة قياسية بالقواعد.
الحد الافتراضي 5 خطط بالذكاء الاصطناعي لكل مستخدم يومياً (للتحكم في التكلفة) — عدّله في `MAX_AI_PLANS_PER_DAY`.

### 3) تشغيل التطبيق
```bash
cp .env.example .env        # وعبّئ رابط المشروع و anon key
npm install
npx expo start
```
امسح الـ QR من تطبيق **Expo Go** أو شغّل بناء تطوير (`npx expo run:ios` / `npx expo run:android`).

### 4) الاختبارات
```bash
npm run typecheck   # فحص TypeScript
npm test            # مولد الخطة (360 حالة) + InBody + محرك الجاهزية/النوم + المدرب المحلي + قاعدة البيانات (النقاط والصلاحيات والخصوصية والمزامنة)
```

### 5) الإطلاق التجريبي ثم النشر على المتاجر
الخطوات الكاملة للإطلاق التجريبي (TestFlight و Google Play اختبار داخلي والتحديثات الفورية) في **[BETA.md](BETA.md)**.

```bash
npx eas-cli@latest build --platform all
npx eas-cli@latest submit
```
غيّر `bundleIdentifier` و `package` في `app.json` قبل النشر.

## الخصوصية والأمان
- الوزن والطول والجنس وصور الجسم في جداول/حاوية **خاصة** لا يقرأها إلا صاحبها (Row Level Security).
- المنشورات افتراضياً للأصدقاء فقط، ويقدر المستخدم يخليها للجميع.
- النقاط والسلسلة لا تُكتب إلا من دوال الخادم.
- مفتاح Claude محفوظ في أسرار Supabase ولا يوصل للتطبيق.
- بيانات الصحة اليومية (نوم، نبض، HRV) خاصة بصاحبها؛ الأصدقاء يرون **عدد الخطوات فقط** عبر دالة الترتيب. الكتابة فقط عبر `sync_daily_health` مع حدود منطقية للقيم.

## ملاحظات مهمة قبل الإطلاق
- **توثيق الأندية**: أي مستخدم يقدر يضيف نادي، لكن النقاط تُحتسب فقط في الأندية الموثّقة (`verified = true`) لمنع الغش (مثل إضافة "نادي" في البيت). وثّق الأندية من لوحة Supabase أو ابنِ لوحة إدارة.
- **تزوير الموقع**: التحقق بالموقع يمنع أغلب الغش، لكن الموقع المزيّف (Fake GPS) ممكن. للمستوى الأعلى أضف QR Code داخل النادي أو شراكة مع أنظمة دخول الأندية.
- **التوقيت**: "اليوم" محسوب بتوقيت الرياض في `app_today()` — عدّله لو توسعت لدول ثانية.
- **الإشعارات** (طلب صداقة، دعوة تحدٍّ، تعليق) غير مضافة بعد — الخطوة التالية المقترحة: `expo-notifications` + Database Webhooks.
- الخطة إرشادات لياقة عامة وليست استشارة طبية (مذكور في التطبيق).
